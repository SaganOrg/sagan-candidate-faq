# Fonts

## SpaceGrotesk-var-latin.woff2

Space Grotesk, variable weight axis 300-700, subset to Latin and Latin
Extended. 26 KB.

Licensed under the SIL Open Font Licence 1.1 - see `OFL.txt`, which must stay
alongside the font file.

Regenerated from the upstream variable TTF with:

```bash
pyftsubset SpaceGrotesk-VariableFont_wght.ttf \
  --output-file=SpaceGrotesk-var-latin.woff2 \
  --flavor=woff2 --layout-features="*" --name-IDs="*" \
  --unicodes="U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+2074,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD"
```
